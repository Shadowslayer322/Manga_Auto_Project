1. Lee `C:\Manga_Auto_Project\LECCIONES_APRENDIDAS.md` y el script afectado (`scripts\pipeline_completo.py`, `scripts\limpieza_rapida.py`, `scripts\ocr_ingles.py`, `scripts\typeo_core.py`, etc.).
2. Aplica el cambio o mejora solicitada por el usuario directamente sobre el código existente (sin crear archivos duplicados).
3. Añade la nueva regla o solución con fecha de hoy en `C:\Manga_Auto_Project\LECCIONES_APRENDIDAS.md` (y marca como `"RESUELTO"` cualquier entrada pendiente en `REPORTE_ERRORES.json` si aplica).
4. Confirma brevemente qué archivo modificaste y qué regla quedó aprendida para los próximos capítulos.
